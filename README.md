## 👋 Welcome to plane 🚀

Plane - Linear/Jira alternative

## 📋 Description

Linear/Jira alternative

## 🚀 Services

- **app**: Plane (`makeplane/plane-web:latest`)

## 📦 Installation

```shell
composemgr install plane
```

## 🔧 Configuration

```shell
TZ=America/New_York
BASE_HOST_NAME=plane.example.com
```

## 🌐 Access

- **Plane**: http://localhost:3000

## 📂 Volumes

- `./rootfs/data/plane` - Application data

## 🔐 Security

- Change default passwords
- Configure HTTPS with reverse proxy
- Regular backups
